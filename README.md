# Prat-s-AI-

This is an AI base model and framework created by a 15-year-old boy "me" / Prateek Pandey.

## 🚀 About the Project
Prat-s-AI- is a custom-built AI framework featuring a custom transformer architecture, tokenization pipelines, training utilities, and a clean user interface. 

## 🛠️ Project Structure
* **`model/`** - Core architecture including custom attention mechanisms, embeddings, and GPT blocks.
* **`inference/`** - Engines and generators handling model text outputs.
* **`tokenizer/`** - Custom Byte Pair Encoding (BPE) implementation.
* **`training/`** - Data scheduling, dataset wrappers, and training loop logic.
* **`ui/`** - A local web interface to interact with the model seamlessly.

## 💻 Getting Started
1. Clone this repository.
2. Install the dependencies listed in `requirements.txt`.
3. Run `run.py` or launch the UI using `ui/app.py`.
